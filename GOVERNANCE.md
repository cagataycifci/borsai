# Governance

Borsa AI Terminal is currently maintained by a solo maintainer, Çağatay Çiftçi.

## Decision making

- Bug fixes and small improvements are handled through pull requests.
- Large, breaking, data-licensing, or security-sensitive changes should start with an issue or design discussion.
- Decisions prioritize user safety, reproducibility, maintainability, and licensing compliance.

## Maintainer responsibilities

- Review and merge pull requests.
- Triage issues and security reports.
- Maintain releases and documentation.
- Disclose project limitations honestly.
- Avoid presenting synthetic activity or unverified usage as community adoption.

Governance can evolve as sustained external contributors join the project.
